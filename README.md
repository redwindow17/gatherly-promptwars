# Gatherly

A celebration planner for weddings, birthdays, and community events. Turn an event brief into an editable budget, dated tasks, vendor questions, and personalized ideas—then keep planning when real costs or priorities change.

Built for **PromptWars Virtual, Challenge 5: Celebration & Event Planner**.

[Open Gatherly](https://gatherly-planner.halishrichard17.workers.dev). Deployment verified on 1 November 2026. The published app currently offers labelled starter plans; live Gemini generation awaits configuration of the server secret and a successful live test.

## What works

- **Gemini planning:** a server-side Google Gemini call returns structured suggestions tailored to the brief. The UI exposes the actual prompt, response, and model for inspection.
- **Honest budgets:** integer-paise allocation, a separate 10% contingency, editable estimates, and immediate overspend feedback. Editing a cost never silently changes other categories.
- **Actionable timelines:** date-only arithmetic, the event host's timezone, urgent flags when preparation time is short, editable owners/dates, and completion tracking.
- **Vendor due diligence:** questions about availability, costs, access, setup, dietary needs, and cancellation terms. These are checklists, not fabricated vendor recommendations or confirmed quotes.
- **Personalized ideas:** Gemini suggestions with assumptions to review. Authored starter templates remain available and are clearly labelled as non-AI.
- **Local plans:** versioned browser storage, schema validation, and recovery protection for damaged data. No login or server-side event database.
- **Take the plan with you:** printable plan and an escaped, folded RFC 5545 calendar export compatible with calendar apps, including Google Calendar.

## Run locally

Use Node.js 22.12+ (tested on Node 24) and npm.

```sh
npm ci
npm run build
npm run worker:dev
```

Open `http://127.0.0.1:8787`. This serves the production build and the API together.

For hot reload, keep the Worker running and run `npm run dev` in a second terminal. Vite serves `http://127.0.0.1:5173` and proxies `/api` to the local Worker.

To enable real AI, add the following **locally** to `.dev.vars`, using a key from Google AI Studio. The file is ignored by Git.

```dotenv
GEMINI_API_KEY=your-own-key
```

`wrangler.jsonc` configures the model. The default is `gemini-3.8-flash`, based on Google's model documentation checked on 1 November 2026. Availability and quota depend on your Google project; choose another supported Gemini model if necessary. Never place the key in a `VITE_` variable or frontend code. Without a key, the app reports that live AI is unavailable and offers labelled starter plans; it does not pretend those templates came from Gemini.

## Architecture

```text
React event brief → POST /api/plan → validate input and rate limit
                                      ↓
                              Google Gemini JSON response
                                      ↓
                            validate model output
                                      ↓
                    deterministic budget/date calculations
                                      ↓
React editable plan ← validated plan + actual AI activity
        ↓
Versioned local storage / print / calendar export
```

`src/domain` owns money, dates, schemas, starter templates, and calendar export. `src/components` contains the form, budget editor, and plan views. `worker` owns the HTTP boundary and the Gemini adapter. Browser and Worker TypeScript configurations are separate to avoid mixing incompatible ambient DOM types. `worker/env.d.ts` is generated by Wrangler.

## Deploy to Cloudflare

```sh
npx wrangler login
npm run build
npx wrangler deploy --dry-run
npx wrangler deploy
npx wrangler secret put GEMINI_API_KEY
```

Cloudflare hosts static assets and the server endpoint. Google Gemini supplies generation. Calendar export is a standards-based file export, not a Google Calendar API integration. No other Google service is claimed.

The two rate-limit bindings restrict generation to 6 requests/minute per address and 40/minute for the shared endpoint **per Cloudflare location**. These distributed counters are approximate, not a hard global spending cap. Shared-network users can share the address allowance. Configure a separate Google project quota/budget appropriate to your deployment; no paid resources are automatically provisioned by this project.

## Privacy, assumptions, and limits

- Generating with Gemini sends the entered event brief to Google. Saved plans, edits, and AI transcripts stay in this browser; clearing browser storage removes them. Avoid including unnecessary private contact or identity details.
- Costs are estimates in INR. Confirm quotes, accessibility arrangements, permissions, and vendor terms yourself. The app makes no bookings and contacts no vendors.
- Suggestions may be wrong. Output is validated structurally, but hosts must review its practical suitability.
- A revised brief creates a separate plan so manual edits can remain in the original. The browser holds up to 12 plans. At capacity, generation asks you to print or export and explicitly delete a plan; it never silently evicts your work.
- API errors never silently replace a plan with canned AI output. The host chooses a starter plan explicitly.
- No ranking, judging score, or competition outcome is promised.
